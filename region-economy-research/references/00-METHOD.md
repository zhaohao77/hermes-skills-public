# 00 · 方法层（与区县无关，换任何地方都用这份）

> 这一层只写**方法**，不写任何具体地名、企业名、金额。具体区县的数据在 `instances/<区县>-<年份>/`。
> 判据：三个月后、换到另一个省，这份文件里的每一句还成立。

## 1. 准入四道闸（判据，不是例子）

| 闸 | 收 | 不收 | 判据（机械可核） |
|---|---|---|---|
| 时间 | 数据年份 ≥ 当年-2 | 更早的只能标「历史线索·不予使用」 | 每条记录带 `YYYY年` 或发布日期 |
| 主体 | 有限公司 / 股份公司 / 合伙企业 | 合作社、种植园、家庭农场、农庄、基地、市场、中心、平台、协会、联合体、管委会、村集体、景区 | 名称后缀匹配，或主体类型字段 |
| 行业 | 制造（装备/新材料/电子/医药/食品加工）、种业、农业产业化龙头 | 4S/经销商/汽贸、餐饮住宿、物流快递冷链、房地产物业、家具木业、航空机场、整车厂、文旅景区、教育培训 | 名称+经营范围两列正则 |
| 来源 | 能点开的 URL + 数据年份 | 拿不到链接就写「原文链接未收录」+ 媒体名 + 日期 | URL 非空且可 200 打开 |

> **个体户怎么办（判据要老实说）**：个体户与个人独资企业的名称**没有统一后缀**（`XX经营部`/`XX商行`/`XX加工厂`/`XX门市部`…），靠名称正则判断必然一漏一大批。所以——**名称匹配不到公司后缀的不等于不是经营主体，标 `△待核` 单独成页**，贷前用工商/征信核实主体类型，不要直接删。若确有需要，在 config 里开 `include_individual` 把这类后缀一起收进来（默认关，因为噪音大）。

**例外：大型批发市场不算企业客户，但要单列「市场载体·批量入口」**——运营主体（公司制）可进主表做授信，市场整体作为批量入口：向运营方要商户名录 + 摊位租金台账，按租金/流水定额度，先试 30 户再复制。

## 4. 五层工作流（每层的输入/输出）

| 层 | 输入 | 动作 | 输出 |
|---|---|---|---|
| 0 历史交付物 | 任务主题 | 先搜本地是否已有同主题报告（桌面/Documents/知识库） | 已知结论清单，防白做 |
| 1 宏观底盘 | 区县名 | 政府工作报告 + 统计公报 | 表：GDP/预算收入/规上/固投/市场主体/专精特新数/排名（每条带出处+年份） |
| 2 平台园区 | 区县名 | 园区年度总结表彰报道 | 表：园区/主导产业/龙头/规上数/出口 |
| 3 镇街地图 | 镇街清单 | 按片区派并行子代理（每组 3-6 个） | 每镇街：基本情况/优势产业/重点企业+数据+URL/机会点 |
| 4 前N名单 | 「要前 20」时 | 表彰榜 → 省市榜单反查 → 专精特新公示 → 规上名录 → 镇情名片 | 名单 + 更正与待核附录 |
| 5 竞争与策略 | 本地同业 | 挖农商行/城商行投放、金融专员、产品 | 竞争格局 + 差异化赛道 + 90 天路线 |

**子代理纪律**：任务小到 10 分钟内完成；**先落盘 JSON 再写文字**；context 里必须带已知线索防重复；结果是自报，关键数据主代理抽查。

## 5. 输出表结构（三张表 + 两卡）

**主表（每镇街）**：企业全称 / 镇街 / 行业 / 关键数据（带年份） / 认定 / 名称核验 / 来源URL

**市场载体表**：载体 / 运营主体 / 规模数据（带年份） / 批量入口怎么做 / 风险 / 来源

**剔除表**：企业 / 剔除原因（写清撞了哪道闸）

**跑前核实卡**：待核项 / 现场问谁 / 问清后怎么用（每行都要有第三列，否则等于问卷）

**拜访路线图**：周次 / 天 / 片区 / 镇街 / 车程 / 企业 / 行业 / 切入点 / 建议产品 / 来源

## 6. 四道审计（交付前必跑）

1. **名称回源**：每条名单去它自己的来源页找这个名字，找不到进「待核清单」
2. **剔除词复查**：名称+行业两列正则过一遍四道闸的剔除词
3. **年份与链接**：年份达标、URL 非空、抽检 10 条能打开
4. **数字回原文**：每个数字/百分比/认定要在它自己那条来源里找得到——**找不到就删数字，不删企业**

审计完再对一遍正文叙述数字（家数、剔除数、待核数），必须与脚本算出的数一致。

## 7. 路线图排法（避免碎片天）

不要按镇街单独切天；按**片区拉平**，每 5 家一天，允许跨镇合并（相邻镇拼一天）；远镇同一天连跑不穿插；专精特新与前半天可信度 A 的排前半周。

## 8. 数字纪律（业务口径，不许破）

- 每个数字带年份，没年份不进表
- 每条来源能点开看到这个名字
- 数字对不上删数字、名称对不上换来源，两者都做不到进「待核」
- **不估算**：用户说“估一下”一律答「未查到」，走现场三问（营收/参保/他行授信）
- 宏观与竞争只给原文句，**口径由人定**（镇本级 vs 含园区常差 20 倍）
