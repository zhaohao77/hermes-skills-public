# 实例层（instances）

每个区县一个目录：`<区县>-<年份>/`

```
<区县>-<年份>/
├── INDEX.md            # 10 行：覆盖了什么、数据截止日、已知缺口
├── 00-宏观与产业.md     # 第 1-2 层产出
├── 01-镇街地图.md       # 第 3 层产出（可按片区拆多个文件）
└── 02-重点企业清单.md   # 第 4 层产出（含更正与待核附录）
```

**规则：实例层只放数据与「这次怎么做的」，方法一律回 `../00-METHOD.md`，不要复制。**

本仓库不附带任何真实区县数据——请自行建立自己的实例目录（含企业名单与政府来源链接，建议放私有仓库）。
