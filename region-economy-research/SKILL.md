# 区域经济调研：从「要拓展业务」到「能直接跑的客户名单」

把一句模糊的「我们要拓展某区县业务」变成三件可执行的东西：**客户名单 + 拜访路线 + 待核清单**。

定位：**区域级 pre-marketing 调研**。输出企业候选池之后，才进入企业级尽调（征信/授信调查）。

> 换一个区县先看 `references/00-TRANSFER-CHECKLIST.md`（6 步 30 分钟）+ `configs/_SCHEMA.md`（每个字段从哪查）。
> 方法层 `references/00-METHOD.md` 不用改，只换 config 和实例目录。

---

## 一、何时使用

- 「调研 XX 县/区/乡镇经济」「XX 街道有什么产业」「每个镇营收前 20 的企业」
- 拓展普惠/对公前的区域摸底、网点选址、政府或园区对接
- 需要竞争对标（本地农商行、城商行打法）与差异化赛道

## 二、先分流，别上来就开干

| 用户要的是 | 走哪条路 | 耗时 |
|---|---|---|
| 能直接跑的**名单 + 路线 + 审计**（机器产物） | `scripts/research_pipeline.py` | 脚本约 8 分钟，不含人工复审 |
| **为什么 / 怎么打**（竞争格局、客群分层、90 天路线） | 下面的五层工作流 | 半天 |
| 两样都要 | 脚本先出名单，五层再出策略，合成一份 | 半天 |

**判据一句话：要数字跑脚本，要判断跑五层。**

搞反的后果很具体：用子代理去读两千篇文章会超时；用脚本写竞争格局写不出来。

## 三、准入四道闸（全过才收）

| 闸 | 收 | 不收 | 判据（机械可核） |
|---|---|---|---|
| **时间** | 数据年份 ≥ 当年-2 | 更早的只标「历史线索·不予使用」 | 每条记录带 `YYYY年` 或发布日期 |
| **主体** | 有限公司 / 股份公司 / 合伙企业 / 个体户 | 合作社、种植园、家庭农场、农庄、基地、市场、中心、平台、协会、联合体、管委会、村集体、景区 | 名称后缀匹配，或主体类型字段 |
| **行业** | 制造（装备/新材料/电子/医药/食品加工）、种业、农业产业化龙头 | 4S/经销商/汽贸、餐饮住宿、物流快递冷链、房地产物业、家具木业、航空机场、整车厂、文旅景区、教育培训 | 名称 + 经营范围两列正则 |
| **来源** | 能点开的 URL + 数据年份 | 拿不到链接就写「原文链接未收录」+ 媒体名 + 日期 | URL 非空且能 200 打开 |

**三条硬规则：**

1. **时间闸不可松**。十年前的地方报纸报道会把人带进坑里——曾有报道把两家早已注销的合作社写成"现代农业公司"，直接变成幽灵客户。
2. **主体闸要老实**。个体户与个人独资企业的名称没有统一后缀（`XX经营部`/`XX商行`/`XX加工厂`/`XX门市部`…），靠名称正则必然漏一大批。匹配不到公司后缀的**不等于不是经营主体**，标 `△待核` 单独成页，贷前用工商/征信核实，不要直接删。
3. **剔除后要报数字**。交名单时先给「原 N 条 → 剔除 M 条（分类计数）→ 保留 K 条 → 其中有近两年数据的 J 条」。否则对方不知道这张表能不能直接跑。

### 例外：大型批发市场不是单户客户，是「批量入口」

大型批发市场**不进企业主表**，但要单列一页「市场载体」：

| 列 | 要求 |
|---|---|
| 载体 / 运营主体 | 运营方是公司制的，可以同时进企业主表做授信 |
| 规模数据 | 必须带年份（商户数、交易额、日均吞吐） |
| 批量入口 | **动作级**：向运营方要商户名录 + 摊位租金台账，按租金定额度（不看报表）；由市场方推荐首批 30 户试点，跑通复制 |
| 风险 | 腾退不确定性、商户多为租赁摊位无产权（只能做流水贷不能做抵押） |

市场里的 4S 店、经销商本体仍然不进主表——**留载体，不留单户**，两者不矛盾。

## 四、五层调研工作流

### 第 0 层 · 先查历史交付物（最容易白做一遍的一步）

做新报告前，先 `search_files` 搜本地是否已有同主题的历史交付物（桌面、Documents、知识库目录、runtime 版本目录）。

**规律**：`references/` 存的是**原始数据**；历史交付物（docx/pdf）存的是**分析框架与结论**（竞争格局、客群分层、渠道打法、路线图、风控要点）。两者都要看，缺一个必遗漏。

**旧清单必须做新鲜度标记**：逐家用正则提取 `(20\d\d)年` 取最新年份，四档写进表格列——
`✅ 近两年` / `🟡 3-4 年前` / `⚠️ 更早需更新` / `⚪ 未标年份需核实`。

对 ⚠️/⚪ 的处理：**只核查头部**（上市、营收 10 亿+、国家级小巨人，约 30 家），3 路并行派子 agent，每家查四件事：最新营收（带年份）/ 认定状态变化 / 重大变化（上市·破产·搬迁·扩产）/ 查不到写「未查到新数据」。剩下几百家不硬查——中小企业本来不公开财报，正确做法是标出来 + 提示贷前走税务/工商核实。

**交付话术**：不要只说「已整合 336 家」，要先把新鲜度分布摆出来（多少 ✅、多少 ⚪）。

### 第 1 层 · 宏观底盘（自己搜，2-3 轮并行）

政府工作报告 / 两会报告（GDP、一般公共预算收入、规工增加值、年度目标）最权威，优先；再补县域排名（百强县/中小城市指数）、行政区划与人口、市场主体总量、专精特新梯队总量。

### 第 2 层 · 平台与园区

国家级/省级园区（经开区、高新区、综保区、临空区、自贸区）的主导产业、龙头企业、规工与出口数据。**园区年度总结表彰大会的报道常能挖出完整企业名单**，是最被低估的矿。

### 第 3 层 · 镇街地图（派并行子代理分片）

- 按地理/产业分片：城区街道组 / 中南部镇组 / 北部镇组（每组 3-6 个，受并发上限分批）
- 子代理 context 必须给足：①已掌握的宏观/园区数据（防重复劳动）②该组每个镇街的已知线索 ③输出格式（每镇街：基本情况/优势产业/重点企业+数据+来源URL/专精特新/园区市场/机会点）
- 硬要求：**查不到写「未查到」，禁止编造**；每条关键信息附来源 URL
- **子代理结果是自报**：纳税额、企业名单等关键数据，主代理必须抽查验证后再入报告

### 第 4 层 · 前 N 企业名单（「要前 20」时）

镇级**没有**官方纳税排名，按这个顺序拼：

1. 镇街/园区「税收贡献十强」「突出贡献企业」「高质量发展大会」表彰（最接近官方排名）
2. 省市级榜单反查：民企百强、高企税收贡献百强、制造业百强
3. 专精特新小巨人公示（国家级/省级分层）、上市及上市后备名单
4. 规上工业企业名单、产业集群成员名单（国家中小企业特色产业集群）
5. 镇情名片报道（党报「我是XX镇」系列，含总量+点名龙头）、政府项目摘牌/签约公告、龙头企业认定名单、工商黄页（核经营状态）

农业/文旅小镇凑不满 20 家是正常的，如实说明，别硬塞；城区街道用亿元楼宇/专业市场交易额/规上数替代。

### 第 5 层 · 竞争格局 + 业务策略

- 必挖：本地农商行/城商行（普惠主力）的贷款投放、金融专员数量、特色产品、政银合作模式、特色支行打法
- 差异化赛道（大行难覆盖、农商行也难覆盖的）：供应链金融、科技贷/专精特新贷、技改设备更新贷、外贸/跨境电商、农业产业链、会展文旅新业态
- 结尾必须给：客群分层金字塔、产品匹配矩阵、渠道打法（政银企对接/园区金融驿站/小个专指导站/商会协会/供应链平台）、90 天路线图、风控要点

## 五、数据源分级（写类型，不用记具体站名）

| 级 | 类型 | 为什么可靠 |
|---|---|---|
| **A** | 区县政府网「政务公开」下的镇街工作动态 / 部门动态 | 一线走访签约扩产的一手记录，企业名单最全 |
| **A** | 政府工作报告 / 财政预算报告 / 发改计划报告 | 宏观底盘唯一权威 |
| **A** | 省工信厅专精特新公示、上市及后备名单 | 认定类信息唯一权威 |
| **B** | 本地党报专题（区县专版、镇情名片系列） | 镇级披露不足时的补救 |
| **B** | 省级/地市党报与区域新闻门户 | 补充事件 |
| **C** | 企业黄页、招聘页、自媒体 | **只作线索**，必须交叉验证 |

## 六、输出物：三张表 + 两卡

| 产物 | 列 |
|---|---|
| **企业主表**（每镇街一表） | 企业全称 / 镇街 / 行业 / 关键数据（带年份） / 认定 / 名称核验 / 来源URL |
| **市场载体表** | 载体 / 运营主体 / 规模数据（带年份） / 批量入口怎么做 / 风险 / 来源 |
| **剔除表** | 企业 / 剔除原因（写清撞了哪道闸） |
| **跑前核实卡** | 待核项 / 现场问谁 / 问清后怎么用（第三列不能空，否则等于问卷） |
| **拜访路线图** | 周次 / 天 / 片区 / 镇街 / 车程 / 企业 / 行业 / 切入点 / 建议产品 / 来源 |

**报告结构**：摘要 → 区域经济总览表 → 重点平台 → 镇街经济地图（逐个）→ 企业梯队/专精特新 → 竞争格局 → 业务拓展策略 → 数据来源与局限性。

**路线图排法**（避免碎片天）：不按镇街单独切天；按**片区拉平**，每 5 家一天，允许相邻镇拼一天；远镇同一天连跑不穿插；认定等级高的排前半周。

## 七、四道审计（交付前必跑）

1. **名称回源**：每条名单去它自己的来源页找这个名字，找不到进「待核清单」
2. **剔除词复查**：名称 + 行业两列正则过一遍四道闸的剔除词
3. **年份与链接**：年份达标、URL 非空、抽检 10 条能打开
4. **数字回原文**：每个数字/百分比/认定要在它自己那条来源里找得到——**找不到就删数字，不删企业**

审计完再对一遍正文叙述数字（家数、剔除数、待核数），必须与脚本算出的数一致。

## 八、Pitfalls（同类任务高频坑）

### 名称类（最严重）

- **★ 名称幻觉**：报道里出现并列/模糊写法（如「A/B 现代农业」），被拆成两家独立公司并自动补行政区划，实际查无这两家。四条硬规则：
  1. 并列写法要么照抄原文、要么写「（原报道写法：A/B，主体待核）」，**禁止拆成独立公司**
  2. **禁止给报道里的简称自动补「XX县/XX市」前缀**——前缀一加就是一家不存在的法人
  3. 名单只收能授信的经营主体，合作社/种植园/家庭农场/农庄/基地一律标 △ 当线索
  4. 每条交付前回源文件 grep 一次名称，源里查不到的字面名一律标「需核全称」
- **属地错配**：线索常把知名企业挂错镇。归类前用注册地址/工商信息核。
- **宣传口径 ≠ 注册地**：镇街宣传会把大企业挂本镇（工厂主体其实在园区）。按表彰口径归镇，但注明「注册地待核」。
- **同名企业**：多镇都有同名或近似主体，一律按注册地归镇。
- **企业更名**：新旧名并用检索。
- **黄页必核经营状态**：已注销主体不能当存量客户。

### 数据类

- 同段提两家公司时，关键数据可能错配到另一家——逐条回原文确认「这个数字是不是这家的」
- 宏观口径由人定：镇本级 vs 含园区常差一个数量级，报告里必须写清用的哪个口径
- 认定状态会变（专精特新到期、上市变动），引用年份过期的认定要标「需复核」

## 九、数字纪律（不许破）

- 每个数字带年份，没年份不进表
- 每条来源能点开看到这个名字
- 数字对不上删数字、名称对不上换来源，两者都做不到进「待核」
- **不估算**：用户说「估一下」一律答「未查到」，走现场三问（营收/参保/他行授信）
- 宏观与竞争只给原文句，口径由人定
