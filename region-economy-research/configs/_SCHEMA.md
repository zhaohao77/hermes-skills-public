# configs 字段说明（换区县照着填）

> 每换一个区县：复制 `example.json` → 改名 → 按下表逐字段替换。
> **字段从哪查**写在「怎么拿到」列，别看例子猜。**填错的典型后果**也写上，省一轮返工。

| 字段 | 作用 | 怎么拿到 | 填错会怎样 |
|---|---|---|---|
| `region` | 报告标题与摘要用 | 行政区标准全称 | 报告标题写成“本区县” |
| `base_url` | 政府网根地址 | 搜「XX县人民政府」官网 | 全站 404 / 抓回 0 篇 |
| `min_year` | 时间闸门 | 默认 当年-2 | 旧闻混进名单 |
| **`town_url_tpl`** | **镇街列表页路径模板**，`{code}` 代入栏目码 | **手工点开任一个镇的页面，抄 URL 里到代码之前那一段**。例：`http://x.gov.cn/zwgk/zjdxxgkml/<栏目码>/` → `/zwgk/zjdxxgkml/{code}/` | **每个镇都抓回 0 篇**（政务网路径各区县完全不同） |
| **`chan_regex`** | 从镇街页里发现子栏目的正则，第 1 个捕获组 = 栏目码 | 看镇街页 HTML 里怎么跳转：meta refresh 形如 `url=./xxgkzn1/` 用默认；纯字母栏目码把 `\d+` 改成 `\d*` 或去掉 | 栏目发现为空 → 该镇 0 篇 |
| **`min_corpus`** | 语料量下限，低于就告警 | 按本地发文量定，一般 200-500 | 定太高会把“真跑了但量少”误判为没跑通 |
| `body_regex`（可选） | 正文容器正则（第 1 捕获组=正文 HTML），不填则自动取「最长的那块」 | 抓到的正文明显太短（几十字）时才需要填 | 不填一般也行——脚本会自动在所有候选容器里取最长；实在匹配不到再显式指定 |
| `towns` | 镇街 → 栏目码，**两种写法**：① `"示例街道": "qtjd"` ② `"示例街道": {"code":"qtjd","channels":["gzdt1252","tzgg"]}` | 打开每个镇页面，URL 里的目录段就是 code；有多个栏目的用写法 ② | 代码猜错 = 该镇 0 篇（不报错，最坑） |
| `town_order` | 报告与路线图里的镇街顺序（按片区排，不是拼音） | 自己按地理片区排一份 | 报告镇街顺序变拼音序，跟人工排的对不上 |
| `county_prefix` | 县级新闻栏目父路径 | 政务公开 → 新闻动态 | 宏观/竞争两章全“未检到” |
| `county_channels` | 县级各子栏目 | 同上，取 URL 最后一段 | 同上 |
| `max_pages` | 每栏目翻页数 | 看列表页总数，8 一般够 2 年 | 抓不全 / 白抓 |
| `workers` | 并发线程 | 别超 12（政府网扛不住） | 被 429 / 封 IP |
| `sleep` | 每页间隔秒 | 被 429 就加大 | 同上 |
| `exclude_words` | 剔除行业词 | **本地支柱行业要单独判断**：花炮、陶瓷、烟花这类在别县是主力，一刀切会把好客户剔光 | 候选被剔空（语料上千篇却 0 家） |
| `keep_words` | 优先收的行业/认定词 | 本地主导产业 + 专精特新/小巨人 | 排序失真 |
| `foreign_prefixes` | 外地地名前缀表 | 防止收进外地企业 | 名单混入外省主体 |
| `out_dir` | 产物目录 | 每个区县单独一个目录 | 复用旧目录会覆盖旧语料（已丢过两次 2,809 篇） |

## 三个坑（都真踩过）

1. **`towns` 的代码猜不得**：猜错不报错，只是抓回 0 篇。先手工点开一次镇页面，从 URL 抄。
2. **`town_url_tpl` 是换区县的第一道关**：参考实例是 `/zwgk/zjdxxgkml/{code}/`，别的区县可能完全不同（如 `/zwgk/zfxxgk/bmxzjdgk/xzjd/{code}/`）。**照抄任何现成模板都必 404**。
3. **镇街名称含「乡」**：有的区县是「镇+乡+街道」三套（例：30+ 个乡镇街道含某乡）。`towns` 里照标准全称写，别只写镇和街道。

## `--picks`（人工复审名单）字段清单，少一个就 KeyError

`picks.json` 必须是对象数组，每条**至少**含这 6 个键（照 `keep.json` 抄最稳）：

```json
[{"镇街": "示例街道", "企业": "XX有限公司", "行业": "装备",
  "关键数据": "2025年营收2.1亿元（原文）", "认定": "省专精特新", "来源": "http://..."}]
```

`认定` 可空字符串；`镇街` 为空会直接 KeyError（脚本第 464 行排序用），所以宁写 `"镇街":"待核"` 也别漏。
