# 携程订单与票面口径（某日 实测）

> 触发：要核「他到底买没买 / 买了哪档 / 票含哪些园 / 花多少钱 / 几晚」时。
> **订单是比任何攻略都硬的"用户事实源"** —— 交付物写的票务口径必须与它对齐。

## 一、问道 API **查不到**个人订单（别试第二次）

`POST https://wendao-skill-prod.ctrip.com/skill/query` 喂「帮我查我账号上的订单记录」→ 它明确回：

> 「抱歉，我无法直接访问您的携程个人账号订单数据」

→ **问道是"问产品/政策"的脑，不是"读我的账号"的接口。** 个人订单只能走下面的页面路线。

问道适合问：某景区/场馆的**开放时间、预约方式、免票口径、场次、玩法**（本轮用它问到二七纪念塔
「免费 · 需预约 · 持身份证原件 · 09:00–17:00（16:30 停止入园）」与汴河游船购票方式）。

⚠️ **它是第三方 AI 正文，价格/时间进交付物前必须第二来源交叉核对**：
本轮汴河游船夜游，问道说「成人 50 / 优待 25」，开封本地宝/旅泊网/马蜂窝给出 40 / 60 / 80 三种价，
口径随航段与年份变 → **交付物改写区间「夜游单程约 40–60 元/人，1.2m 以下免」**，并把「码头随买随用」写死。

## 二、订单页走法（Edge CDP + Playwright，用用户的登录态）

前提：Edge 以调试模式启动（`--remote-debugging-port=9223 --remote-allow-origins=*`，
`--user-data-dir=$HOME\EdgeProfile`），登录态在其中。

```python
page.goto("https://my.ctrip.com/", wait_until="commit", timeout=45000)  # ⚠️ commit，别用 load/domcontentloaded
page.wait_for_timeout(7000)
txt = page.inner_text("body")        # 首页直接列出「待出行」订单
# 全量（可在线查近一年）：点页内「更多订单」→ 或直接开
page.goto("https://my.ctrip.com/myinfo/all")
```

- 登录标志：页面出现「**尊敬的黄金贵宾**」= 登录态在；出现登录框 = 未登录，先让用户扫码（别猜密码）。
- 列表字段：订单号 · 预订日期 · **票面全称** · 使用日期 · 份数 · 入住人 · 金额（或「离店后付 ¥X」）。
- 页面还写明「您可以在线查看近一年订单」——超出一年才需要 App/客服。
- ⚠️ **部分订单「仅支持手机端查询」** → 桌面端点不开详情，**票面细则（如"赠三园是否三日内有效"）取不到**
  → 交付物改写成「以票面/景区公告为准」，**不要替它下结论**。
- ⚠️ **一次只开一个 URL，`wait_until="commit"`**。本轮曾一次串 3 个候选网址、每个等 7 秒，
  整条命令 130 s 无响应（用户直接问「卡住了？」）→ 改成"先开首页、再看页内链接"后 **9–18 秒**出结果。

## 三、票面全称 = 票务口径（本轮最有用的一招）

订单标题自带细则，**直接拿它反查交付物对不对**：

| 订单票面原文 | 真实口径 | 交付物原写的（错） |
|:--|:--|:--|
| 万岁山武侠城门票(赠翰园碑林+城墙景区+铁塔公园门票)（**单日不限次入园**） | 万岁山当日不限次进出 + 赠三园（有效期以票面为准） | 「赠三园仍是三天不限次」（未证实） |
| 清明上河园门票(**当日且单次有效**) | 当日有效 · **单次入园**（出园不可再进） | 「10/4 当日不限次」 |
| 只有河南·戏剧幻城一日票 1大1小-12:00场-幻城剧场 | 已约 12:00 场 · 1大1小×2 份 | （一致） |
| 河南博物院散拼团人工讲解(含门票预约)亲子票1大1小-13:30场-2小时 | 13:30 场 · 2 小时 · 已含门票预约 | （一致） |

⚠️ 「实名分时预约」这类词也要对票面：票面没写分时段 ⇒ 交付物只能写「**实名入园**」。

## 四、订单反推票档 + 「没在清单里 = 没买」

- **金额反推档位**：清明上河园 ¥360 = 成人 120×2 + 优待 60×2；万岁山 ¥300 = 100×2 + 50×2
  ⇒ 孩子们都按**优待档**（同时反证孩子 >1.2m，可给其余按身高的景区定档）。
- **订单缺席 = 没买**：全量清单里没有「汴河游船」SKU ⇒ 交付物写的「游船已在联票内」不成立
  （他买的是 100/50 元的万岁山门票，游船是**另一个 128/68 元 SKU**）。
- **逐项对表**：金额 · 含哪些园 · 使用日期 · 入住人 · 晚数 · 房型 · 场次，一次全对完，
  发现的口径错误按「能改的直接改、拿不准的标注来源」处理。

## 五、与 12306 的分工

| 要核什么 | 走谁 |
|:--|:--|
| 车次 / 停站 / 时刻 / 票价（铁路） | 12306（见 `rail-and-feasibility-tooling.md` §1a）——**机票火车票不在携程订单里** |
| 门票 / 酒店 / 演出 / 讲解（程内产品） | **携程订单页**（本节） |
| 景区政策 / 场次 / 免票口径 | 携程问道 API（本节 §1，需第二来源）或景区公众号 |
