# 版式与配色规范

## 画布

- **1080 × 1920**（9:16），手机全屏无黑边——**别改比例**
- 米色网格纸：底色 `#FAF6EC` + 34px 双向网格线 `rgba(140,160,180,.15)`

## 配色（语义固定，别乱用）

| 色值 | 用途 |
|---|---|
| **赭红 `#B5544A`** | **游玩日** Day 徽章 / 强调卡底色 / 硬提醒卡 / 关键词高亮 |
| **蓝 `#4A6FA5`** | **赶路日** Day 徽章（一天一个色系，翻页时一眼分得清） |
| 卡片左色条 · 蓝 `#5C7FA3` | 行程 / 交通 / 换乘 |
| 卡片左色条 · 红 `#B5544A` | 硬提醒 / 收尾（最后一步） |
| 卡片左色条 · 黄 `#D9A62E` | 餐饮 |
| 卡片左色条 · 绿 `#6E9E78` | 游玩时段 |
| 卡片左色条 · 紫 `#8E86B8` | 夜场 |
| 气泡 · 黄 `#FFF6D6` + 边 `#E3C465` | 普通提示 |
| 气泡 · 红 `#FDE7E3` + 边 `#D98A80` | 警示（每天最多 1 个） |

## 字号层级（1080 宽下实测可用）

| 元素 | 字号 |
|---|---|
| Day 徽章 | 50px 黑体加粗 |
| 页面主标题 h1 | 42px |
| 副标题行 | 23px |
| 强调卡主信息 | 35px 黑体加粗 |
| 卡片主信息 `.val` | 28px |
| 卡片补充 `.sub` | 23px |
| 卡片标签 `.lab` | 21px |
| 景点横幅标签 | 27px 黑体 |
| 底部面板正文 | 23px |
| 气泡 | 22px |

> ⚠️ **主标题超过约 14 个汉字会换行**（实测"长沙 → 郑州 → 中牟 · 出发日"被挤成两行）
> → 缩短 h1，把"出发日"这类修饰词挪到副标题行。

## 信息层级（从上到下，权重递减）

1. Day 徽章 + 城市/主题
2. **景点通栏图**（有景点时）
3. 路线节点（编号 + 时间 + 地点 + 动作）
4. **硬卡点强调卡**（发车/开演/散场/末班车）
5. 餐饮 / 住宿 / 接驳卡
6. 底部「费用 + 强度/必备」双栏
7. 提醒气泡

> **装饰（胶带、图钉、卡片轻微旋转）永远不能压过 3–5 的信息。**
> 旋转幅度控制在 ±1.5° 内，只为"手账感"，不能影响阅读。

## 内容取舍（最容易做错的地方）

**必放**：
- 硬时间点：发车 / 开演 / 散场 / 接驳车 / 退房
- 地点名 + 交通方式 + **耗时**
- 门票 / 预约状态 / 天数有效期
- 住宿名 + 关键电话
- **1–2 条避雷**（如"避开某剧场""别订错某家店"）

**可删**：
- 景点历史介绍、文化背景
- 通用旅游 tips（"建议带防晒""注意安全"）
- 已经在别页写过的重复信息

**原则**：**「旅途中一眼能看懂怎么走」 > 「信息完整」**。
宁可少写，不可糊成一片——user 明确说过要"给孩子提前视觉效果"，**图是给孩子看的，成年人的信息量要克制**。

## 打卡框

每个节点右上角放 `☐`（26×26，圆角，灰边框）——给孩子勾"这个完成了"，增加参与感。
强调卡（赝红底）里用**描边空心框**，不抢反白色的主信息。

## 每页必须自检的三件事（交付前）

1. **中文有没有乱码**（HTML 渲染不会乱码；若乱码说明你可能误用了文生图）
2. **有没有溢出/被截断**（DOM 高度必须 = 1920，超出就压间距）
3. **底部有没有大片留白**（用 `body{display:flex; flex-direction:column; justify-content:space-between}` 吃掉）
