## 1. 开本与像素换算

| 开本 | @300dpi（px） | 比例 | 用途 |
|---|---|---|---|
| A4 竖 | 2480 × 3508 | 1:1.414 | 日记作文纸 |
| **A3 竖** | **3508 × 4961** | 1:1.414 | **装订册页**（手账 / 路线图 / 日记） |

**为什么必须用 px 不用 mm**：HTML 里写 `width:210mm` 时，Playwright 在 2480px+ 的 viewport 下
**不会把 mm 铺满画布** → 内容**缩在左上角约 1/4**，右下方整片空白。
（此坑先在 A4 日记纸上踩到，A3 同理。）→ **一律全用 px**。

**常用量换算（@300dpi，1mm ≈ 11.81px，1pt ≈ 4.17px）**：

| 设计值 | px |
|---|---|
| 页边距 14 / 15 / 10 mm | 165 / 177 / 118 |
| 行高 10.2 mm | 132 |
| 正文 12 pt | 50 |
| Day 徽章 20 pt | 83 |

## 2. 从 9:16 手账页 → A3 页：不能缩放，只能重排

**9:16 = 1:1.778，A3 = 1:1.414** → 比例不同，硬缩放会变形或留大白边。

**手账页各元素在 A3 上的典型放大倍率**（以 1080×1920 → 3508×4961 为例，约 2.6× 宽、2.6× 高）：

| 元素 | 手机版（1080×1920） | A3 版（3508×4961） |
|---|---|---|
| body padding | 22 / 26 / 18 | 150 / 195 / 130 |
| Day 徽章 font-size | 50 | 112 |
| 标题 h1 | 42 | 98 |
| 景点图高度 | 238–240 | **560** |
| 卡片 padding | 11 / 17 | 22 / 40 |
| 卡 lab / val / sub | 21 / 28 / 23 | 48 / 66 / 52 |
| 节点 margin-bottom | 10 | 17 |
| 编号圆点 | 32 | 88 |
| 正文卡 border-left | 9 | 30 |

**别一步到位**：先按 2.6× 铺一版，再按实测高度压 1–2 轮。

## 3. 高度配平流程（必做）

```python
page.set_viewport_size({"width": 3508, "height": 4961})
page.goto(url, wait_until="load", timeout=90000)
# 等图真加载：complete 之外还要 naturalWidth > 0
page.wait_for_function(
    "Array.from(document.images).every(i => i.complete && i.naturalWidth > 0)",
    timeout=40000)
page.wait_for_timeout(3000)          # 大版面渲染慢，给足余量
h = page.evaluate("document.body.scrollHeight")
print("DOM", h, "/ 4961, 差", h - 4961)
page.screenshot(path=out, clip={"x":0,"y":0,"width":3508,"height":4961}, timeout=120000)
```

**实测路径（本次 D2）**：

| 轮次 | 总高 | 差 | 动作 |
|---|---|---|---|
| 初版（2.6× 直铺） | 5801 | +840 | 字号/间距各压一轮（25 处替换） |
| 第 2 轮 | 5418 | +457 | 景点图 660→560、字号再缩、间距再缩（21 处替换） |
| 第 3 轮 | **4961** | **0** | ✅ 收工 |

**调节顺序（压不动时按此优先级，别删内容）**：
1. **缩景点图高度**（一次能省 80–100px）
2. **缩字号**（lab / val / sub / 卡片字号，整体缩 8% 省约 200px）
3. **缩节点间距与 padding**（节点 margin-bottom、卡片 padding，7 个节点省约 40–60px）

**亏欠方向也要管**：总高**小于** 4961 就是下方留白 →
用 `body { display:flex; flex-direction:column; justify-content:space-between }` 吃掉，
**但必须同时加 `flex-shrink:0`**（见下节）。

## 4. ⚠️ 最大的坑：flex 会压缩子元素

**症状**：`body` 加了 `justify-content:space-between` 后，内容超出画布时
**顶部景点图被挤成约 60px 的细条**（CSS 明确写着 `height:560px`）。

**为什么会误判**：`document.images` 里 `naturalWidth` 是**正常的 4032**
（因为图确实加载了，只是显示区域被压缩）→ 第一轮误判成"图片没加载"，
白白去查文件路径和等待逻辑。

**修法**：给固定内容块**逐个加 `flex-shrink:0`**：

```css
.head, .hero-img, .intro, .booklink, .route, .bottom, .bubbles { flex-shrink: 0; }
```

**判别口诀**：
- flex 填留白 = **内容不够时**用的手段；
- **内容一超出，flex 就反噬去压元素** → 这时正确动作是**缩内容**（第 3 节的调节顺序），
  不是继续调图片路径。

**自检**：量关键块的实际高度，与 CSS 声明值对不上就是被压了：
```python
page.evaluate("() => ({h: document.body.scrollHeight, "
              "hero: Math.round(document.querySelector('.hero-img').getBoundingClientRect().height)})")
# hero 输出 60 而 CSS 写 560 → 被 flex 压了
```

## 5. ⚠️ 第二个坑：原图分辨率不够会糊成色块

- **手机版（1080px 宽）**：用 1080px 的图完全没问题。
- **A3 版**：内容区宽约 **3168px** → **原图宽必须 ≥3000px**，否则放大后糊。

**本次的处置**：D2 原来用 `src_18.jpg`（**1080×413**）→ A3 上糊成深色条。
回头在同一批已下载的图里挑高分辨率的：
`src_17.jpg`（**4032×3024**，"我是河南人"夯土墙）→ 换上后清晰。

**手头素材的分辨率体检**（先跑这一步再选图）：

```python
from PIL import Image
import os
for f in sorted(os.listdir(d)):
    if f.lower().endswith(('.jpg', '.png')):
        print(Image.open(os.path.join(d, f)).size, f)   # 挑宽 ≥3000 的
```

**项目实测可用高清图**（供同类行程参考）：
| 景点 | 可用文件 | 分辨率 |
|---|---|---|
| 只有河南 | `imgs/src_17.jpg` | 4032×3024 |
| 清明上河园 | `imgs_pano/q_c.jpg` | 4608×3456 |
| 龙门石窟 | `imgs_d5/lu_06.jpg` | 3648×1472 |
| 万岁山 | `imgs_d34/d3_03.jpg` | 2048×1045（**A3 略勉强，可再找**） |

**校验**：渲染后 `page.evaluate` 打印 `i.naturalWidth`，
明显小于 3168 就说明会糊 —— 别等用户说"图怎么是糊的"。

## 6. 装订册的建议结构

开本统一后，主动给用户**装订顺序**方案让他确认（别让他自己想）：

```
封面
路线图（横版或竖版，真实地理版）
Day1 手账  →  Day1 日记
Day2 手账  →  Day2 日记
…
DayN 手账  →  DayN 日记
封底
```

**按天交替**优于"先全部手账、再全部日记"：孩子一天翻到"今天玩什么 + 今天写什么"，
两页连在一起，实际使用最顺。

**可选追加**：出一份**按此顺序拼好的 PDF**，直接拿去打印店
（多页 PNG 合成即可）。
