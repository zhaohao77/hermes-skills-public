# 儿童版行程页（给小学生读的手账页）—— 规格 / 模板 / 实测数字

> 由来：某日 用户「**把我的行程D1-D6能不能改的更合适小学生看的**」。
> 我先量化诊断（见下），给 A/B/C 三选一，他选 **B：另做一套儿童版，家长版原样保留**。
> 与铁律 8（真名+第二人称）、铁律 10（A4 日记纸）、铁律 13（行前片单）同属「给孩子看的一类页」。

## 0. 一句话定位

| | 家长版手账 | **儿童版手账** |
|:--|:--|:--|
| 定位 | 途中执行手册（时刻/换乘/费用/兜底） | **给孩子读的一页**（今天去哪、看到什么、我该做什么） |
| 读者 | 家长 | **姐姐（四年级）/ 妹妹（二年级）** |
| 文字量 | 716–1146 字/页 | **≈260 字/页** |
| 成人术语 | 5–13 个 | **0 个** |
| 注音 | 无 | **生字/地名用 `<ruby>`** |
| 时刻信息 | 完整时刻表 | **藏进任务里**（"车 14:52 开，只停 11 分钟"） |
| 关系 | 不动，继续用 | **另一套页，不是家长版的缩水版** |

**关键判断**：孩子读不动 **≠** 要删家长信息 —— 家长要的是可执行，孩子要的是可读；
**正解是分层（另开一套），不是把家长版改浅。**

## 1. 先诊断，别直接改（30 秒）

```powershell
python <skill_dir>/scripts/kid_readability.py <页面目录> [页面文件...]
```

量三个数：**汉字量 / 成人向术语数 / 带声调字母数（注音）**。
本项目家长版实测（某日）：

| 页 | 汉字量 | 成人术语 | 术语样例 |
|:--|--:|--:|:--|
| D1 | 716 | 10 | 出站×5 检票口 换乘 进站 已付 |
| D2 | 783 | 13 | 接驳×2 预约×2 错峰×2 兜底 候客点 |
| D3/D4 | 971/976 | 6/5 | 票面×2 不限次 单次入园 实名 |
| D5/D6 | 1146/1114 | 8/13 | 预约×2 寄存×4 返程×2 网约车 动线 |

⚠️ 脚本里的「最长句/平均句长」指标在本项目**不可用** —— 手账页是**标签式短语**（`🏠 13:45 出门 · 打车 20 分钟`）
而非完整句子，按标点切句会把整块当成一句。**只看汉字量与术语数两个准指标。**

## 2. 儿童版页面规格（D1 样张定稿，vision 复核通过）

### 画布 / 视觉（沿用家长版，别另起一套皮）
```css
body{ width:1080px; height:1920px; overflow:hidden; padding:24px 26px 20px;
      font-family:"楷体","KaiTi","STKaiti",serif; color:#2B2B2B; background-color:#FAF6EC;
      background-image:linear-gradient(rgba(140,160,180,.15) 1px,transparent 1px),
                       linear-gradient(90deg,rgba(140,160,180,.15) 1px,transparent 1px);
      background-size:34px 34px;
      display:flex; flex-direction:column; justify-content:space-between; }
.daybadge{ ... white-space:nowrap; }   /* 不加会被挤成两行（铁律13 实测） */
```
字号比家长版**大一档**（孩子读）：`今天一句话 40px` · `卡片标题 33px` · `卡片说明 26px` · `块标题 30px` ·
`ruby rt 15px`。

### 结构（固定 6 块，别自由发挥）
1. **页头**：`Day N` 徽章 + 「今天去看 XXX」+ 日期/出发日/孩子名 + 天气小框（沿用家长版 `.head` 布局）
2. **🔎 今天一句话**（≈40 字，一句讲清"今天去哪、那是什么地方"）
3. **👀 你会看到**（3 条，每条 ≤ 20 字标题 + 一句话说明）
4. **🎯 你的 3 个任务**（可勾选 `.box` 方框；**灵魂所在**）
5. **📖 记住这一件事**（把铁律 7 的课本连线压成一句，**不写年级课号**——那是给家长的）
6. **🍜 今天要吃的**（铁律 1 附则的当地特色，压成一行 + 一句点法）
7. **页脚一问**（"今天最想记住的一件事，晚上讲给爸爸妈妈听"）

### 任务化写法（把行程变成游戏）
| 家长版原文 | 儿童版任务 |
|:--|:--|
| 14:52 目的地站发车（停 11 分钟） | 在高铁上找到「**目的地站名**」三个字，念给妹妹听。车 14:52 开，只停 11 分钟 |
| 地铁 8 号线 + 出站打车 | 数一数今天一共坐了几种车？到了河南，看看有没有第 4 种 |
| 「一部河南史，半部中国史」 | 问爸爸一个问题：为什么河南叫「**中原**」？ |

**判据**：每条任务必须**当场可做**（找字/数数/提问），不是"注意安全"这类空话。

### 生字注音（二年级硬需求）
```html
<ruby>郑州<rt>zhèng zhōu</rt></ruby> · <ruby>中牟<rt>zhōng móu</rt></ruby> · <ruby>胡辣汤<rt>hú là tāng</rt></ruby>
```
**只给地名 + 生字/菜名注音**，整篇注音会挤爆版面。

### 出发日 / 返程日（无景点）→ 用「路程条」代替配图
铁律 1 规定无景点日不配图。儿童版补一条**纯 CSS 路程条**（虚线框 + 图标 + ruby 地名 + 交通方式）：
```
🏠 长沙  ——🚄 高铁 3小时48分——▶  🏙️ 郑州  ——🚇🚕 地铁+打车 约40分钟——▶  🎭 中牟
```
**有景点的天**：照铁律 1 用当天景点 hero 图（沿用家长版那张，别另找）。

## 3. 交付流程

1. **先出 D1 样张**（`scripts/render_one_page.py --html <kid_d1.html> --out <样张.png>`）—— 别一次做 6 页
2. **vision 复核**：徽章是否折行 · 有没有文字被裁 · 拼音是否压住汉字 · 底部是否大片空白
3. 用户确认后**再批量 D2–D6**
4. **并册 or 独立**由他选：A 并进 A4 册（每天排在家长版后）/ B 独立一套 PNG / C 先调整
5. 若并册 → 走铁律 6 / 23 的**多载体收口**（A4 页 + PDF 页序重建）

## 4. 判据与反例

**通过标准**：**孩子会主动翻** = ①一屏读完（不翻页）②有能勾的任务 ③生字有提示 ④图上没有一处是他读不懂的术语

❌ 反例（别做）：
- 把家长版**删字改浅**当儿童版（家长要的时刻/费用就没了，两头不讨好）
- 儿童版里继续写「已购 / 已预约 / 14:30 前到站台」（**票务状态与执行细节不属于孩子**）
- 满页 emoji 无文字（二年级要的是**能读的字**，不是贴纸墙）
- 只做一页就批量（**没经过样张确认的批量 = 6 页返工**）
