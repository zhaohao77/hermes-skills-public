# 手机版行程页（单文件 H5）—— 载体规范 + 国内托管选型

## 1. 载体定位

与手账图 PNG / A4 装订册 PDF / Word 攻略 / 竖版路线图**并列独立**的第 5 类旅行交付物。
用途：**旅行中在手机上查**（现场、走路时、信号差时）。不是给孩子的图，也不是打印件。

改一处要全载体同步的纪律同样适用：H5 是独立载体，**不要默认它跟着别的载体一起改**，
也不要在没要求时把它当成「A4 的替代」而撤掉 A4。

## 2. 样式规范

- 单文件 HTML、`max-width:640px` 居中、基准字号 16px、行高 1.75（手机阅读舒适区）
- **粘顶日期导航**：D1–D6 + 应急 + 清单，横向滚动 chip，当前项高亮
- **卡片式时间线**：左侧时间（flex 固定 62px）、右侧内容
- **警示块分三级**：红块（走错站 / 接站电话 / 务必到站台的时间点）> 蓝块（兜底方案）> 灰块（补充）
- **可折叠 `<details>`**：景点典故、打包清单、附录默认收起，避免一屏过长
- **手账图来源就是 1080×1920**（手机竖屏尺寸）→ 可直接内嵌，无需重排
- 底部固定「↑ 顶部」按钮

## 3. ★★ 托管选型：给国内用户做线上交付，**先实测可达性再推荐**

**本次实锤**：官方技能 `web-development/cloudflare-temporary-deploy` 的
`npx wrangler deploy --temporary` **技术上完全跑通** —— 零账号创建临时账号、部署成功、拿到
`https://<name>.<account>.workers.dev`。

**但 `*.workers.dev` 在国内被 DNS 污染**：`nslookup` 返回 Facebook 的假 IP
（`2a03:2880:...:face:b00c`）、`curl` 连接 **20 秒超时**（HTTP 000）。
⇒ **用户手机上根本打不开。**

**铁律：「部署成功」≠「用户能访问」。** 推荐任何托管前，先 `curl -s -m 20 -o /dev/null -w "%{http_code}"`
实测目标域名；对国内用户**不要**把海外托管（Vercel / Netlify / Cloudflare Pages / GitHub Pages）当默认推荐。

**国内可用通道（按零依赖程度排）**：

| 方案 | 手机能看 | 怎么改 | 成本 |
|:--|:--|:--|:--|
| **单文件 HTML + 微信传** | ✅ 离线也能看，可「添加到主屏幕」像 App | 我改完重发 | 0，不用账号 |
| 国内静态托管（腾讯云 COS / 阿里云 OSS / Gitee Pages） | ✅ 真公网 URL，永远最新 | 我改完自动生效 | 需账号 |
| 在线文档（腾讯文档 / 飞书） | ✅ | 用户自己手机上就能改 | 0，排版弱 |

## 4. 「实时帮助」的现实边界（必须如实告知，不要承诺做不到的）

- 用户在旅行中**只有手机、家里电脑不在** → 真·AI 对话需要额外一台公网后端，当前没有通道。
- ❌ **不要承诺「页面里能问 AI」**，也不要说「早上开机跑一下」这类他拿不到的方案。
- ✅ 落地替代 = **离线应急卡**：按「每种意外给 2–3 条备选」写，而不是泛泛的「注意事项」。本次已覆盖：
  叫不到车（提前预约 → 出租车候客点 → 酒店接驳 三层兜底）、雨天停演（改室内 / 用不限次进出回酒店歇）、
  走错站（哪个站下车 / 哪个站才对）、联系电话。

## 7. v2 实战：现场功能三件套 + 四个真坑（某日 落地）

用户：「不是做儿童版，是**你直接进化到最优秀的版本**」。落地物：`桌面/河南6日亲子游/河南6日亲子游_手机版.html`（**2.75 MB**，13 张图内嵌），
构建器 `桌面/河南6日亲子游/h5/build_h5.py`（改内容只改这个脚本的 DAYS/APPENDIX，重跑即得）。

### 加进去的现场功能（技能前六节没写的）

| 功能 | 做法 | 验收方式 |
|:--|:--|:--|
| **顶部「现在」条** | JS 用本地日期在 `DAYS`（`某日`…）里取 `cur`；再拿节点上的 `data-t="HH:MM"` 逐条比较 → 输出「现在应该 X / 下一件 Y」 | ★**必须用假时间验收**：`page.add_init_script` 覆盖 `Date` 到行程中某天 —— 实测 10/3 14:20 输出「现在应该：下午刷演出 + NPC 互动｜下一件 17:30 — 晚饭」✅ |

| 打印 | `@media print` 隐藏导航/浮动按钮/导航chip | — |

### 四个真坑（都是本轮踩的，脚本自检查不到）

1. **构建器用 `.replace('{CSS}', …)` 占位符时，JS 里的花括号绝不要写成 `{{ }}`** —— 那是 `.format()` 的写法，在 `replace` 流程里会**原样输出成 `{{`** → JS 语法错。
   ✅ 验收：把 `<script>` 段抽出来落盘，跑 **`node --check`**（本机 node 可用）。
2. **`scrollIntoView` 自动定位后，sticky 的「现在」条会被导航遮住** —— 因为导航在窄屏会**换行**（`flex-wrap`），写死 `top:48px` 不够。
   ✅ 修法：`nowbar.style.top = nav.offsetHeight + 2 + 'px'`，并监听 `resize` 重算。
3. **导航 chip 行用 `overflow-x:auto` 在 390px 下右端硬裁**（vision 一眼看出，`scrollWidth` 自检查不出）→ 改 **`flex-wrap:wrap`**，全部可见、不用横滑。
4. **浮动「↑顶部」按钮压住卡片底部文字** → 做小（`padding:9px 14px`、`opacity:.93`）。

### 交付前的视觉复核（不可省）

用 **headless Edge** 按 **390×844** 渲染截图（`pw.chromium.launch(channel='msedge', headless=True)`，别去动用户正在用的 Edge 会话），
再丢给 vision 逐张问「有无裁切/重叠/溢出」—— 本轮就是靠它抓出上面第 2/3/4 条。
⚠️ **vision 会把相似布局认错**（本次把 D3 的节点说成 D2），
**结构类结论以 DOM 自检（`querySelectorAll` 计数 / 文本）为准，视觉只用来抓裁切与遮挡**。

## 8. ★ 地图联动：高德 `/search` 会报「版本不支持此功能」（某日 用户实机反馈）

**症状**：H5 里每个地点给 `https://uri.amap.com/search?keyword=<地名>`，用户点了 →
高德 App 弹「**版本不支持此功能**」。

**根因**：`uri.amap.com/search` 不是给 App 唤起用的（高德 App 不认这个 path）。
正解 = **`/marker` + 真实坐标 + `src` 参数**：
```
https://uri.amap.com/marker?position=<lng,lat>&name=<名称>&src=<来源标识>&coordinate=gaode&callnative=1
```
（**`src` 必填**，缺了唤起失败；高德坐标系标 `coordinate=gaode`）

**坐标从哪来**：高德 REST `https://restapi.amap.com/v3/place/text?key=..&keywords=..&city=..`
→ `pois[0].location` = `"lng,lat"`（GCJ-02，可直接给 marker 用）。本机 key 在环境变量
`AMAP_WEBSERVICE_KEY` / `AMAP_KEY` / `AMAP_API_KEY`（本次实测均可查）。

**⚠️ 酒店名里带景区名的会被同名酒店带偏**（技能铁律 23 早就记过，这次又中）：
搜「开封万岁山武侠城河南大学亚朵酒店」→ 高德返回「**开封清明上河园龙亭公园亚朵酒店**」（离景区 10 km+）。
→ 这类地点**一律用手工实测坐标**（河大亚朵 `114.323881,34.817724`）。

**★ 最关键的一条：App 能不能唤起，电脑上验不了。** 所以 UI **不能只给一个入口**，必须给多方案：

| 选项 | URL | 为何保留 |
|:--|:--|:--|
| 高德地图 App | `uri.amap.com/marker?...&callnative=1` | 装了高德且版本支持时体验最好 |
| **网页地图** | `https://www.amap.com/search?query=<地名>` | ✅ **实测 HTTP 200**，不依赖 App、微信里也能开 —— **保底方案** |
| **腾讯地图** | `https://apis.map.qq.com/uri/v1/marker?marker=coord:<lat>,<lng>;title=<名>&referer=<来源>` | 腾讯 URI 服务**自动带 key**（无需自申请），微信是自家的不拦 |
| 复制地名 | JS `execCommand('copy')` | 100% 可用的兜底（`file://` 下 `navigator.clipboard` 不可用 → 必须用 textarea+execCommand） |

⚠️ **腾讯的坐标顺序是 `纬度,经度`（lat,lng），与高德的 `经度,纬度` 相反** —— 写反了会落到南极附近。

**交互形态**：点 🧭 按钮 → 底部 sheet 四选一（`position:fixed;inset:0` 遮罩 + `.sh` 上圆角面板），
比把 15 个按钮排两行更好。DOM 验收：`#sheet` 的 `display` 变 `flex`、三个 `href` 格式对、无 pageerror。

**微信内的现实**：微信内置浏览器对外链唤起普遍拦截 → 引导用户**用手机浏览器打开 HTML 本身**（而不是微信内置）。
这条要**主动告知**，否则用户会以为链接坏了。

**✅ 实机验收（某日）**：用户回复「初步测了可以用了」→ **多入口方案在真机上成立**；
三个入口均保留（未指明具体哪个通了；不同场景——微信内 / 手机浏览器 / 现场网络——表现不同，不宜收窄成一个）。
**结论：无法在电脑上验证的“App 唤起”，就用“多入口 + 网页地图保底”解决，不要赌单一方案。**

## 7. 单文件构建器配方（数据驱动，别手写整份 HTML）

本项目落地：`$HOME\Desktop\河南6日亲子游\h5\build_h5.py` → 产出 `河南6日亲子游_手机版.html`（**2.48 MB**，7 张图内嵌）。
**内容层与模板分离**：一个 `DAYS` 列表（`dict`：`id/tag/date/title/wx/tl/warn/tips/eat/stay/textbook/spot`）+ 一个 `day_html(d)` ——
**改行程只改数据，不动模板**；附录用 `APPENDIX = [(标题, html串), ...]` 列表。

```python
def b64(path, w=1000, q=78):          # 1080×1920 手账图 → 1000 宽 / q78 ≈ 220–300 KB/张
    im = Image.open(path).convert('RGB')
    if im.width > w: im = im.resize((w, int(im.height*w/im.width)), Image.LANCZOS)
    buf = io.BytesIO(); im.save(buf, 'JPEG', quality=q, optimize=True)
    return 'data:image/jpeg;base64,' + base64.b64encode(buf.getvalue()).decode(), len(buf.getvalue())//1024

# 模板用 .replace 占位符，**禁止 f-string**（CSS 里全是 {}，f-string 当场炸）
html = html.replace('{CSS}', CSS).replace('{DAY0}', ...)
for k, v in IMGS.items(): html = html.replace('{IMG_%s}' % k.upper(), v)   # d1..d6 → {IMG_D1}
```

**三条纪律**
1. **写盘后必须 grep 占位符残留**：`grep -o '{[A-Z_0-9]*}' f.html | wc -l` 应为 **0**；漏替换会静默留一个空 `src`，页面只表现为"少张图"。顺手核 `grep -c '<img'` 与 `data:image/jpeg;base64` 数量是否等于内嵌图数。
2. **`%` 格式化与中文混排会炸**：`print('【分档】前日 PF<=-3% 之后…' % x)` 报 `ValueError: unsupported format character`（裸 `%` 后跟中文）→ 模板串里的裸 `%` 一律写 `%%`。
3. 图片键名与天 id 对齐，改天号时两边一起改。

## 9. 交付话术（本次实测有效）

- **怎么传到手机**：发到微信「**文件传输助手**」→ 手机点开 → 用浏览器打开 → 「**添加到主屏幕**」（用起来像 App，且离线可用）。
- **要改**："跟我说改哪儿，我改完重发，你重新传一次"——并说明**内容源是脚本，改一处不会漏掉别的载体**（对应用户长期担心的"改了这处漏了那处"）。
- 单文件 2.5MB 级，微信传文件无压力；**别为了小几百 KB 牺牲清晰度**。
