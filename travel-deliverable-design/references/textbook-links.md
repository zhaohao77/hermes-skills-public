## 一、已核实的课文（河南线，某日 多源核实）

| 课文 | 教材位置 | 对应景点 | 课文与景点的关系 |
|---|---|---|---|
| **《一幅名扬中外的画》** | 部编版**三年级下册 第12课**（第三单元，略读课文） | **开封 · 清明上河园** | 课文讲张择端《清明上河图》，原句「画的是北宋都城**汴梁**热闹的场面」——**汴梁就是开封**。园子是依此画 1:1 复建。 |
| **《景阳冈》**（武松打虎） | 部编版**五年级下册 第6课**（第二单元，精读课文） | **开封 · 万岁山大宋武侠城** | 节选自《水浒传》第二十三回。园内常演《武松醉打蒋门神》《三打祝家庄》等同源故事。**⚠️ 故事发生地在山东阳谷，不是开封**——园子是"把书里的江湖演给你看"。 |

**已核实：小学课本里没有专门写「龙门石窟」「中牟」的课文。**

- 中牟 / 只有河南 → 无对应课文（它的价值是"具身体验"，见第四节「无课文时」）

### ❌ 「以为在课本里，其实不在」清单（某日 逐条查证 —— 现场**别硬套**）

| 常见误解 | 实测结果 |
|---|---|
| **二七纪念塔 / 二七大罢工**（郑州 D6） | ❌ **小学课本没有**。查到的是**七年级道德与法治 上册 第十课《绽放生命之花》**（其中涉及焦裕禄）。D6 走**现场体验**（塔内"二七大罢工"动画片），**不套课本** |
| 包公 / 开封府 / 包公祠 | ❌ 统编版小学语文**无**包公课文（搜到的是"新课标小学语文阅读丛书"这类**课外书**，不是课本） |
| 杨家将 / 天波杨府 | ❌ 无课文 |
| 岳飞 / 朱仙镇岳庙 | ❌ 《满江红》不在小学课本（属中学）；朱仙镇也不在行程 |
| 焦裕禄 / 兰考 | ❌ **七年级**道德与法治内容（兰考属开封辖区，但不在行程） |

**判据：「这是好故事」 ≠ 「这是课本内容」。** 现场讲包公 / 岳飞 / 二七都没问题 ——
但**别标成"这是你课本里学的"**，孩子回学校对不上会让家长失信。

## 二、核实方法（可靠路径）

1. 用**智谱 `search_pro`**搜：`统编版/部编版 小学语文 <课文名> 几年级 第几课`
2. **要求多源一致**才算核实通过——本次《一幅名扬中外的画》在百度文库/21世纪教育网/搜狐/网易 4 源一致；
   《景阳冈》在微信教育号/搜狐/文档之家 3 源一致。
3. 优先采信：**教案/课件/单元教学计划**类来源（会明确写"X年级下册第N课"），
   次选：出版社/教育机构公众号。
4. 结果里若出现**年级互相矛盾**（如同一课文既说三上又说六下）→ 按多数+教材目录二次确认，
   仍不确定就**不写**。

## 三、⚠️ 幻觉源识别（本次实测踩到）

搜索「龙门石窟 课文」时返回过一篇标题像教材的文档，内容**通篇错误**：

| 该文档的说法 | 事实 |
|---|---|
| 「洛阳市初二语文课本，课文是《龙门石窟》」 | 无法在教材目录中核实 |
| 「位于河南省洛阳市**栾川县**境内」 | 龙门石窟在**洛阳市区南郊**伊河两岸，与栾川无关 |
| 「作者杨慎…与李白、杜甫、王维并称**初唐四杰**」 | 初唐四杰是王勃/杨炯/卢照邻/骆宾王；杨慎是明代人 |

**识别信号**：个人上传的"某某市XX年级语文课本"式文档、内容有**基本史地错误**、
无教材目录佐证 → **一律不采信**。
**教训**：`法不轻信` —— 课文出处宁可写"查不到"，也不拿一篇可疑文档当依据。

## 四、卡片文案模板（已按铁律 8 改写成真名 + 第二人称，可直接套）

**课文已学过（姐姐四年级，如三下课文）**：
```
[📖 课本连线] 《<课文名>》· 部编版<X年级下册 第N课> —— 课文写的「<课文原句关键词>」就是这里。
🧒 姐姐（四年级）：你已经学过这篇了 —— 进园去找课文里的「<具体场景>」，
   看看书上写的和现场一样不一样。
🧒 妹妹（二年级）：你明年X年级就会学到这篇。今天先来现场看看，到时候你会喊「我去过！」
```

**课文还没学过（如五下、初中）**：
```
[📖 课本连线] 《<课文名>》· 部编版<X年级下册 第N课> —— <和眼前景点的关系>
🧒 姐姐（四年级）：**你明年五年级就会学到**这篇。先在园里见过「活的<人物/场景>」，
   到那时候读课文，你会特别有画面。
📌 说清楚一件事：<故事发生地 ≠ 景区所在地，避免混淆>
```

**无课文时（改成看点卡）**：
```
[📖 看点在哪] <这个景区独有的玩法/结构> —— <看完你会明白什么>
```

**交付前自检**：卡里搜 `老大`/`老二`/`孩子`/`他`/`她` —— 全部应为 0。
