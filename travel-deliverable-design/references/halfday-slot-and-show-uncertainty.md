## 一、用高德 Web 服务 API 把「车程」变成实测数

**key 本机已配好，别再去申请**：环境变量 `AMAP_WEBSERVICE_KEY` / `AMAP_KEY` / `AMAP_API_KEY`，
或 `hermes-home/skills/life/amap-lbs-skill/config.json` 的 `webServiceKey`。

```python
KEY = os.environ.get("AMAP_WEBSERVICE_KEY") or json.loads(
    Path(r"$HOME\AppData\Roaming\cn.org.hermesagent.desktop\runtime\hermes-home\skills\life\amap-lbs-skill\config.json")
    .read_text(encoding="utf-8"))["webServiceKey"]

def api(path, **p):
    p.update(key=KEY, appname="amap-lbs-skill")          # ★ appname 必填，否则拒答
    # urllib GET + 失败重试 ≤4 次 + time.sleep(1.5)

def geo(addr, city="郑州"):                                # 地址 → "经度,纬度"（经在前！）
    r = api("/v3/geocode/geo", address=addr, city=city)
    return r["geocodes"][0]["location"]

r = api("/v3/direction/driving", origin=酒店坐标, destination=目标坐标)   # 也可 walking / riding / transfer
p = r["route"]["paths"][0]        # p["distance"] 米 · p["duration"] 秒
```

- ⚠️ **QPS 限流**：连续请求会返回 `CUQPS_HAS_EXCEEDED_THE_LIMIT` → 每次之间 `sleep(1.0–1.5s)`、失败重试 ≤4 次。
- ⚠️ 个别名字会 `ENGINE_RESPONSE_DATA_ERROR`（本轮"二七纪念塔"）→ **换近义词重试**（"二七广场"/"德化步行街" 就成功）。
- ⚠️ **高德不给车费，别自造金额**：只给公里/分钟；金额写区间或不写。
  （本轮我自算的"约 104 元"属于自造数，不该进交付物。）
- **一次跑完所有候选**（POI 列表 → 双列输出），别一个点一个点试。
- 顺带可用：`/v5/place/text`（`keywords` + `region` + `city_limit=true` + `show_fields=business` + `sortrule=weight`）
  取**美食/停车场**的口碑前列（评分 · 人均 · 营业时间），是写美食条最省事的来源。

## 二、末班日 / 空档的选点判据（本轮真实候选表）

判据顺序：**① 单程车程 → ② 孩子适配 → ③ 门票与预约门槛 → ④ 雨天可退性**。

| 候选 | 酒店→此处 | 此处→车站 | 门票 / 开放 |
|:--|:--|:--|:--|
| **郑州市动物园** | **1.6 km / 11 分** | 12.8 km / 32 分 | 07:30–18:00；1.4m 以下免；9:30 前动物最活跃；园内可租童车 |
| **河南自然博物馆**（恐龙厅） | 9.9 km / 24 分 | **4.2 km / 17 分** | 免费·需公众号预约；09:00–16:30；14 岁以下随成人免预约；馆内无餐厅 |
| 如意湖·千玺广场（大玉米） | 8.5 km / 19 分 | 6.2 km / 19 分 | 免费全天；看建筑+湖景，孩子趣味一般 |
| 郑州博物馆（文翰街新馆） | 9.5 km / 21 分 | 16.2 km / 28 分 | 免费·实名（可现场领码）；09:00–17:00 |
| 二七塔＋德化街 | 4.7 km / 18 分 | 13.7 km / 32 分 | 免费；上塔需公众号预约 |
| **黄河花园口景区**（用户指定加入备选） | 16.9 km / 29 分 | 29.0 km / 35 分 | **免费 · 全天开放 · 无需预约**；园内无餐饮、洗手间只在入口 |
| **黄河文化公园（降为"跑远选项"）** | 30.3 km / 52 分 | 47.4 km / 57 分 | 成人 48/网购 45 · 优待 24/22 · 1.4m 以下免 · 无需预约；气垫船 80/人、索道往返 40/人 |

**两个关键洞察**：
1. **单程 ≤ 约 20 分钟（≈10 km）才叫"8 点起床也能玩透"**；>30 分钟必须同时给替代方案。
   用户的一句验收话术就是「**有点远，还有其他推荐的吗**」。
2. **末班日的"顺路"是假命题**：行李常寄存酒店 ⇒ 动线是 `景点 → 酒店取行李 → 车站`，
   要看**往返车程**，不是"离车站多近"。47.4 km/57 分的回程直接否掉了黄河文化公园。

**推荐配额**：主推 1 个（最省事）+ 1 个雨天/室内替代 + 其余列成备选，**同一份表里把
`门票 / 开放时间 / 是否要预约` 一起给**，别让用户再问一轮。

## 三、窗口长度决定阈值（半日 vs 全天）—— 当晚的关键改口

用户先给的是半日窗（「起床都要 8 点」），随后明确：
「**D6 是全天备选，从早上 8 点到下午 4 点都是可以自由活动的**」。
窗口从 **2.5h → 8h** 之后，取舍整体变了：

| 窗口 | 阈值 | 本轮结果 |
|:--|:--|:--|
| 半日（约 2.5–3h） | 单程 ≤20 分 / ≤10 km | 只剩动物园、二七塔、如意湖够格 |
| **全天（08:00–16:00）** | 单程 ≤30 分 / ≤20 km 都可 | **花园口（16.9 km/29 分）进卡片**；黄河文化公园降为「跑远选项（也来得及，但来回近 3 小时）」 |

**动作**：① 听到作息/窗口变化**立刻重跑候选表**，别沿用上一轮取舍；
② 把窗口口径写进交付物最显眼处（图上 D6 行：`D6 全天自由活动 08:00–16:00（下 5 处任选）→ 16:00 回酒店取行李 → 16:10 打车 → 16:40 到郑州东`，
Word 附录「前提」段同口径）；
③ **备选不是"替他选"**：用户原话「**这些写上去备选吧**」→ 全部候选卡片化写进交付物（含景观特色，见
`pil-composed-pages.md` 第三节「卡片式备选区」），让他当天按心情挑。

### 黄河花园口景区 · 卡片可用的事实（某日 核实）
- 距酒店 16.9 km / 29 分；从景区回郑州东站 29.0 km / 35 分
- **免费开放 · 全天开放 · 无需预约**（个别体验项目另收费）
- 景观特色：**黄河大堤上看「地上悬河」**（河床高于城区地面，比课本直观）、
  **1938 年花园口决堤纪事广场 · 八卦亭 · 将军坝**（将军坝始建于清乾隆八年 1745 年，堤上最老的险工之一）、
  湿地木栈道观鸟（白鹭/苍鹭）、河边**快艇约 30 元/位**（约 5 分钟）
- ⚠️ 无餐饮、洗手间只在入口，自备干粮与水；河边无遮阳（防晒），**不要下河、别翻护栏**

## 四、演出/夜场类项目：「查不到权威源就不写死」

**核实的现实（某日 实测，万岁山）**：公开渠道**没有任何官方停演公告**。
能查到的官方/媒体事件只有：某日 门票入园政策通知 · 2026-08-11 台风临时闭园 ·
2026-06-06 高考「江湖静音令」（只降爆破/高音特效，不停演）· **2025-11 打铁花因设备维护+环保暂停**
（当时给当日已预约者免费再入园一次作补偿）。携程问道同样答复「暂未查询到停演公告，以景区官方小程序当日节目单为准」。

**景区真实规则**：演出**不提前在网络长期公示**；当日是否上演看**官方小程序当日节目单 + 园区广播**；
**王牌演出多为"入园后公众号约场次"，不是"提前占座"就行** —— 两者是两件事。

**处置模板（可直接抄进交付物）**：
- 节点 lab：`★ 进园先抢约 → 11:00 到「城寨沙场」占座`；
- 节点 sub 首行：`🎫 入园第一件事：公众号抢约《三打祝家庄》+《打铁花》（票量/场次有限，先抢再逛）`；
- 兜底句：「抢不到就改看替补剧目」+ **替补清单**（万岁山常驻）：
  《王婆说媒》《醉打蒋门神》《李逵断案》《林冲战杨志》《好汉行》巡游、神舟广场水幕光影秀；
- 门票口径天然给缓冲：**当日不限次进出** → 换场次还能再进。

**剧目归属必须先核清**（改错景区 = 让用户按错日期做准备）：

| 剧目 | 在哪个景区 |
|:--|:--|
| 《三打祝家庄》《打铁花》《王婆说媒》《李逵断案》 | **万岁山武侠城** |
| 《大宋·杨门女将》（穆桂英/杨家将题材，2026-07 上新） | **清明上河园** |
| 杨家将 / 天波府系 | **天波杨府** |

**话术纪律**：用户说「我听说某剧取消了」→ ① 先穷尽公开渠道（多组关键词 + 问道）；
② 如实回「公开渠道查无公告」+ 官方真实规则；③ **追问一句「你在哪看到的」**（截图/群消息/小程序），
拿不到来源就按上面的模板做「不怕停演」的兜底，**别照传**。
